# L10n Helper

Streamlit 기반 중국어 → 한국어 게임 번역 및 용어 검수 도구입니다.
번역가가 한국어 문장을 직접 편집하고 용어집 준수 여부와 형식 오류를 확인하는 초기 버전입니다.
자동 번역 및 외부 AI API 연동은 포함하지 않습니다.

## 실행

Python 3.10~3.12를 권장합니다.

```bash
python -m venv .venv
source .venv/bin/activate
# Windows: .venv\Scripts\activate
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

브라우저에서 Streamlit이 안내하는 주소를 엽니다. 서버를 외부에 공개할 경우 별도의 인증과 접근 제어가 필요합니다.

## 사용 방법

1. 기본 예제로 시작하거나 UTF-8 CSV를 업로드합니다.
2. 용어집을 추가·수정하고 번역 표의 `ko` 열을 편집합니다.
3. 자동으로 갱신되는 검수 결과를 확인합니다.
4. 번역·검수 결과와 용어집을 CSV로 다운로드합니다.

번역 CSV 필수 열:

```csv
id,zh,ko
quest_001,勇士，欢迎来到王国！,용사여 왕국에 오신 것을 환영합니다!
item_001,获得{count}个钻石,{count}개의 다이아몬드 획득
```

용어집 CSV 필수 열:

```csv
zh,ko
勇士,용사
钻石,다이아몬드
```

쉼표·줄바꿈을 포함하는 셀은 CSV 규칙에 따라 큰따옴표로 감쌉니다. 추가 열은 보존합니다.
다운로드는 Excel에서 열기 쉬운 UTF-8 BOM 형식이며, 수식으로 해석될 수 있는 셀은 작은따옴표를 앞에 붙입니다.

## 검수 범위와 제한

- 빈 번역, 용어집의 권장 한국어 표현 누락
- `{name}`, `%s`, `%1$d` 등의 플레이스홀더와 태그의 종류·개수 불일치
- 한국어 번역에 남아 있는 한자

검수는 단순 문자열·정규식 기반입니다. 태그 순서·중첩, 문맥, 문법, 번역 품질을 보장하지 않습니다.
동의어·조사 변형과 의도된 한자도 경고할 수 있으므로 사람이 최종 판단해야 합니다.
데이터를 외부 번역 API로 전송하거나 데이터베이스에 저장하지 않습니다.
편집 내용은 영구 저장되지 않으므로 파일 교체·세션 종료 전에 다운로드하세요.
